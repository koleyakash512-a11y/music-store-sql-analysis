# music-store-sql-analysis

## About
This project analyzes a digital music store database using MySQL.

## Objectives
- Analyze customer spending
- Find top-selling artists
- Analyze music genres
- Analyze sales and revenue
- Find customer purchasing patterns

## Tools
- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- Subqueries
- CTEs
- Window Functions

## Dataset
Chinook Music Store Database
